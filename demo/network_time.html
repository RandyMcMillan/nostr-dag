About

This page displays the network time offset calculated from peer samples using Cristian's Algorithm. The median offset across all samples is applied to the local clock to produce a consensus time.

When the P2P node is started, it joins the nostr-dag-bridge gossipsub topic and exchanges time queries/responses with any connected peers to reach consensus.

For the full interactive demo with peer sampling and Byzantine-resistant consensus logic, see Byzantine Time Consensus.
